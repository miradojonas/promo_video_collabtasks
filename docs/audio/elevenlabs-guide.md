# Guide ElevenLabs pour CollaB Tasks

## Profil vocal recommandé
Voix neutre-chaleureuse, professionnelle, claire. Éviter trop théâtrale.

## Modèle
Utiliser un modèle narration adapté à la version ElevenLabs disponible.

## Réglages suggérés
| Réglage | Valeur | Notes |
|---|---|---|
| Stability | 70-80% | Équilibre stabilité/expressivité |
| Similarity | ~90% | Naturel |
| Style | 0-10% | Faible pour sobre/professionnel |
| Speed | 0.95-1.0 | Ajuster si trop rapide |

## Stratégie
Générer par segments (plus facile à synchroniser/corriger). Export MP3 44.1/48kHz.
